# student-coach-workflow

学员教练工作流。默认用于训练营、航海、知识付费场景下的学员日志点评、答疑、知识检索与案例沉淀。

## 默认输出规则

- 点评日志时，默认输出 `A版 / B版` 两个备选。
- 每个关键判断尽量附 `<知识库参考>` 或 `<外部参考>`。
- `知识库参考`、`外部参考` 必须独立分行，不能和正文混在同一段里。
- 默认排版为：

```md
A版：

正文第一段

<知识库参考>文件名 / 标题或主题</知识库参考>

正文第二段

<知识库参考>文件名 / 标题或主题</知识库参考>

B版：

正文第一段

<知识库参考>文件名 / 标题或主题</知识库参考>
```

## 说明

- 正文优先口语化，像群里教练直接回复。
- 引用只写真实文件名和真实标题，不编造定位。
- 如果本地知识库未覆盖，再进入外部补检索。
