# 欢迎使用 student-coach-workflow

你现在可以直接做三件事：

1. 贴一条学员日志，让我直接点评
2. 先让我查项目资料，再回学员问题
3. 把课程和项目资料放进 `knowledge-base/01-项目知识库/`，把答疑和案例放进 `knowledge-base/02-答疑案例/`，让我以后按资料来点评

最常用的开口方式：

- `这是学员日志，你来点评`
- `用 student-coach-workflow 点评这条日志`
- `先查 knowledge-base，再回答这个学员问题`
- `帮我把这批资料整理进 knowledge-base`
- `这个点评太空了，按知识库重写`
- `先查公众号，再回答这个问题`
- `本地没找到就去查公众号接口`

默认行为：

- 学员日志会默认按“点评模式”处理
- 一次给你 `A版 / B版` 两个备选
- `A版` 更直接
- `B版` 更陪跑
- 如果本地资料没覆盖，会明确告诉你，不会装成“知识库里有”
- 如果你指定了信息源，比如公众号，会先按你指定的来源查
- 本地没命中时，如果主题适合公众号来源，会先查公众号接口，再补其他来源

资料建议放这里：

- `knowledge-base/01-项目知识库/`
  放课程、项目知识手册、收藏的知识、SOP、外部整理资料
- `knowledge-base/02-答疑案例/`
  放答疑记录、优秀日志、案例拆解、示范点评、常见问题

第一次用，最省事的方式：

1. 先把课程和项目资料丢进 `knowledge-base/01-项目知识库/`
2. 把答疑和案例丢进 `knowledge-base/02-答疑案例/`
3. 再贴一条学员日志
4. 让我先检索，再给你 `A版 / B版`

如果你想先规范学员提交内容，也可以直接说：

- `帮我出一个学员日志模板`
- `按这个 workflow 重写日志模板`
