# 知识入库规范

把训练营、航海、课程、项目知识手册、收藏资料、社群答疑、案例资料放进 `knowledge-base/` 之前，尽量按这个最小规范整理。

## 最小入库格式

每份资料建议至少包含：

```md
# 主题标题

来源：课程 / 群聊 / 教练答疑 / 官方文档 / 外部文章 / 社区讨论 / 用户指定链接
日期：YYYY-MM-DD
适用场景：答疑 / 作业点评 / 任务拆解 / 复盘 / 转化 / 避坑 / 工具安装 / 编码实战

## 核心结论
- 

## 可执行动作
- 

## 常见误区
- 
```

## 目录放置建议

- 课程、项目知识手册、收藏的知识、SOP、外部资料整理，放 `knowledge-base/01-项目知识库/`
- 答疑记录、优秀日志、案例拆解、示范点评、常见问题，放 `knowledge-base/02-答疑案例/`

## 文件命名建议

- `主题-类型.md`
- 示例：
  - `发布节奏-SOP.md`
  - `低转化-FAQ.md`
  - `优秀开头案例-Case.md`
  - `标题违规风险-Risk.md`
  - `环境安装报错-FAQ.md`
  - `代码评审示例-Feedback.md`

## 整理原则

1. 一份资料只讲一个主题
2. 标题尽量直接写问题或动作，不要写得太虚
3. 如果是外部来源，文首必须带链接或来源名称
4. 如果是教练自己的经验，标明是“项目经验”还是“外部经验”

## 为什么要这样整理

因为这个 skill 的核心不是“泛泛会聊”，而是“先检索到能执行的依据，再给学员一个像人说的话的回复”。
