# 学员日志模板

如果你希望点评更稳，先把学员日志输入结构固定住。

## 推荐模板

```md
# 今日行动日志

## 1. 今天完成了什么
- 

## 2. 过程中遇到的问题
- 

## 3. 我现在的判断 / 避坑提醒
- 

## 4. 明天准备做什么
- 

## 5. 关键数据
- 结果数据：
- 关键反馈：
- 遇到的报错 / 卡点：
- 其他观察：
```

## 最低可用模板

如果不想写太多，至少要有这四项：

```md
今天做了什么：

遇到的问题：

我的判断或避坑点：

明天下一步动作：
```

## 教练使用规则

- 日志里如果缺 `问题`，点评重点转向动作延伸和风险提醒。
- 日志里如果缺 `下一步动作`，点评里要帮学员补一个最小下一步。
- 日志里如果缺 `避坑点`，点评里要主动补一个最相关的坑。
- 日志里如果只有情绪没有动作，先提醒学员把实际动作补全，再给有限建议。

## 适合训练营/航海群公告的催交文案

```md
大家写日志的时候尽量别只写“今天有点卡”“感觉不太顺”。
至少补四个信息给教练：
1. 今天具体做了什么
2. 卡在哪
3. 你自己的判断是什么
4. 明天准备怎么继续

这样点评才不会空，大家拿到的建议也会更具体。
```
