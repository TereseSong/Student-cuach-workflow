# 自我进化最小接入方案

目标不是把 `student-coach-workflow` 自动化到很重，而是借 `self-improving-agent` 做一个轻量、稳定、可控的迭代闭环。

## 为什么只做最小接入

这个工作流当前更需要的是：

- 从真实点评里提炼可复用规则
- 发现模板里哪些句式 AI 味重
- 把有效的教练表达写回模板和质检

暂时不需要的是：

- 自动改很多文件
- 自动开 hooks 全局监听所有技能
- 自动生成新的子 skill
- 自动把每次输出都升级成复杂规则

先把“轻学习”跑顺，再考虑“重自动化”。

## 接入目标

最小接入只做 3 件事：

1. 记录本次点评案例
2. 提炼 1 条可复用规则
3. 判断是否需要更新以下 3 类文件之一
   - `references/coach-voice.md`
   - `references/coaching-template.md`
   - `references/review-checklist.md`

## 触发时机

只在下面两种场景触发：

### 场景 1：用户明确要求优化工作流

触发词示例：

- `优化工作流`
- `这个点评 AI 味太重`
- `把这个风格写进 workflow`
- `从这次经验里总结一下`

处理方式：

- 先完成当前任务
- 再进入一次最小自我进化
- 只提炼和本次任务直接相关的规则

### 场景 2：连续出现同类反馈

触发条件：

- 相似问题连续出现 `2-3` 次
- 比如：
  - 引用排版反复出错
  - 开头太 AI
  - 鼓励太空
  - 动作建议太宽

处理方式：

- 不立刻大改全 skill
- 先记入案例
- 确认已形成稳定模式后，再更新对应引用文件

## 暂不自动触发的场景

下面这些场景先不要自动接入：

- 每一次普通点评都自动更新 skill
- Bash 或工具报错后自动修改工作流
- 用户没有反馈，只靠模型自己感觉“可以优化”
- 为了追求完整，自动同时修改多个文件

这些都太容易把工作流改乱。

## 最小输入

每次进入自我进化，只收这 4 类输入：

1. 学员原始日志或原始问题
2. 最终采用答复
3. 用户反馈
4. 本地命中的知识依据

如果没有明确用户反馈，默认只做案例记录，不做规则升级。

## 最小输出

每次最多产出 2 个结果：

1. 一条案例沉淀
2. 一条可复用规则

规则写法要短，最好像这样：

- 学员还没发出第一条视频时，先别陪他抠细节，先逼出首条样本。
- 鼓励不要写“继续加油”，改成确认这一步做对了。
- 引用标签必须独立分行，不和正文混排。

不要一次提炼 5 条，更不要写成长复盘报告。

## 更新优先级

只有在规则足够稳定时，才允许回写 workflow 文件。回写顺序固定：

1. `references/review-checklist.md`
   适合新增质检项、反模式、禁词
2. `references/coaching-template.md`
   适合新增结构顺序、骨架句式、输出格式
3. `references/coach-voice.md`
   适合新增口气特征、判断方式、沟通感规则

如果只是一次性的项目经验，不要改模板，先写进案例库。

## 写入范围

默认只允许写下面两个区域：

- `knowledge-base/02-答疑案例/教练点评迭代案例库.md`
- `references/` 下与本次问题直接相关的单个文件

不要一次同时修改 `SKILL.md`、多个 `references/`、案例库。

## 和 self-improving-agent 的对应关系

把当前 workflow 映射到 `self-improving-agent` 时，建议这样用：

- episodic memory
  对应单次点评案例
- semantic memory
  对应提炼出的短规则
- validation
  对应下次生成点评时，检查这条规则是否真的有用

不建议现在就接它的全局 hooks。
更合适的方式是人工触发或半自动触发。

## 推荐执行顺序

1. 完成当前点评或工作流优化任务
2. 把最终采用答复写入案例库
3. 判断本次是否出现了新的稳定模式
4. 如果有，只提炼 1 条规则
5. 再判断这条规则属于：
   - 口气问题
   - 模板问题
   - 质检问题
6. 最多更新 1 个引用文件

## 判断标准

下面几种情况，值得提炼成规则：

- 用户明确指出“这类问题以后默认别再犯”
- 同类问题已出现多次
- 修正后明显更像真人教练回复
- 这条规则可迁移到别的训练营场景，不只限于图书带货

下面几种情况，不值得升级为规则：

- 只适用于某一本书、某个账号、某一次选品
- 只是这位学员的个人偏好
- 只是措辞微调，没有形成稳定模式

## 非目标

这个最小接入方案明确不做：

- 自动安装或管理其他技能
- 自动生成新 skill
- 自动批量重写整个 workflow
- 自动联网寻找外部教程再改 workflow
- 自动从每次案例里抽很多条规则

## 一句话原则

先把一条有效规则沉淀下来，再考虑让系统自动学会它；不要先把自动化搭很重，再指望它帮你长出判断。
