# Prompt Template

需要复制即用提示词时，用下面模板。

## 模板 1：学员行动日志点评

```md
使用 $student-coach-workflow 处理下面这条学员行动日志。

要求：
1. 先检索当前项目中的本地知识库、课程笔记、SOP、复盘资料或我点名的文件，再开始点评。
2. 如果本地资料未覆盖，再按这个顺序补检索：我指定的来源 -> 官方文档/规则页 -> 高质量外部资料。
3. 从日志中提取：
   - 【待解答】
   - 【待延伸】
   - 【待确认】
4. 输出要像教练在群里聊天回复，口语化，不要写成公文，不要写成完整文章答案。
5. 生成顺序固定为：
   - 先抓日志里的具体处境、动作、数据、卡点
   - 先纠偏一个最容易跑偏的判断
   - 再回答学员最明确的问题
   - 再补明天最该做的 1-2 个动作
   - 最后才决定要不要补一句鼓励
6. 默认一次输出两版点评：
   - A版：更直接，判断更快，动作更短
   - B版：更陪跑，接话感更强，但不许变鸡汤
7. 两版不是同义改写，要有明显口气差异，但核心判断不能互相打架。
8. 每段至少带一个具体锚点：学员原话、动作、数据、结果。没有具体锚点的句子尽量删掉。
9. 少讲意义、方向、阶段、闭环、策略，多讲明天具体怎么做。
10. 禁止使用这些词和句式：
   - 然而、此外、总之、因此、综上所述、例如、基于此、显而易见、值得注意的是、不可否认、换句话说、尽管如此、由此可见、事实上、一方面……另一方面、首先、其次、最后、第一、第二、第三、另外、接下来、然后、最终、总的来说、总结一下、简而言之、当然
   - 你的核心问题是、更稳的做法是、整体来说、你现在不是……而是……、方向开始成型、进入新的阶段、你明天就盯三个动作
11. 默认写成 2-3 段自然聊天文本，不强行列点，不强行上小标题。
12. 每个关键判断尽量附上 `<知识库参考>真实文件名 / 真实标题或主题</知识库参考>`，外部来源写 `<外部参考>来源名 / 主题关键词</外部参考>`。
13. 如果本地知识库没有覆盖，要先标明“本地知识库未覆盖，已进入外部补检索”。
14. 语言要像教练本人在回，不要像 AI 总结，不要用领导发言稿腔。
15. 口气参考 `references/coach-voice.md`：允许有判断，先纠偏，再给动作，不装客观中立。
16. 每版总字数控制在 180-320 字，宁可短，不要写满。

学员行动日志：
{{在这里粘贴日志全文}}
```

## 模板 2：先检索项目知识，再回答问题

```md
使用 $student-coach-workflow 先检索当前项目中的本地知识库和相关资料，再回答这个问题。

要求：
1. 先输出检索到的文件/主题/关键结论。
2. 如果本地资料不够，再按我指定来源 -> 官方文档/规则页 -> 高质量外部资料顺序补检索。
3. 再回答我的问题。
4. 每个关键判断尽量附 `<知识库参考>...</知识库参考>` 或 `<外部参考>...</外部参考>`。
5. 如果本地资料没覆盖，要明确标注未覆盖，不要假装知识库里有。

问题：
{{在这里粘贴问题}}
```

## 模板 3：只做项目知识检索

```md
使用 $student-coach-workflow 检索当前项目里和下面主题相关的知识。

要求：
1. 优先查我点名的文件或目录，其次查 `knowledge-base/`，再查项目中的知识库、课程、SOP、案例、复盘。
2. 输出：
   - 命中的文件或主题
   - 关键结论
   - 可执行动作
   - 未覆盖点
3. 如果本地未覆盖，再按我指定来源 -> 官方文档/规则页 -> 高质量外部资料顺序补检索。
4. 不要直接生成学员点评，除非我再要求。

检索主题：
{{在这里粘贴主题}}
```

## 模板 4：优化学员日志模板

```md
使用 $student-coach-workflow 帮我优化学员行动日志模板。

要求：
1. 让学员更容易写，不要太复杂。
2. 但至少要保证后续点评时能看出：
   - 今天做了什么
   - 卡在哪
   - 学员自己的判断
   - 明天准备做什么
3. 输出一个可直接发群里的模板。
4. 如果有必要，再补一版“最低可用模板”。
```

## 模板 5：批量点评多位学员日志

```md
使用 $student-coach-workflow 处理下面这批学员日志。

要求：
1. 先检索本地知识库，本地未覆盖再补外部来源。
2. 按“我们先看第一位 / 再看第二位”的串讲方式输出。
3. 每位学员都尽量覆盖：
   - 回答问题
   - 下一步动作
   - 避坑提醒
   - 一句具体鼓励
4. 语言要像教练在群里连着点评，不要写成统一模板套话。

学员日志：
{{在这里粘贴多位学员日志}}
```

## 模板 6：训练营学员答疑

```md
使用 $student-coach-workflow 处理下面这个训练营学员问题。

要求：
1. 先检索当前项目中的知识库、课程笔记、FAQ、SOP、代码示例或我点名的文件。
2. 如果本地知识不足，再补查官方文档、API 文档、发布说明或我指定链接。

4. 如果问题涉及报错、环境、依赖、接口调用，优先给排查顺序，不要只讲概念。
5. 每个关键判断尽量附 `<知识库参考>...</知识库参考>` 或 `<外部参考>...</外部参考>`。

学员问题：
{{在这里粘贴问题}}
```
