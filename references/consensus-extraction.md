# 共识问题提炼

这份规则用于把多条学员日志里的重复问题，提炼成一条适合发给圈友的统一提醒。

## 什么时候做

满足任一条件就适合进入：

- 已点评 `3` 条及以上学员日志
- 同一类问题在近期日志里重复出现
- 用户明确说“提炼共识问题”“给圈友统一发一条”

如果只是单条日志，先点评，不强行拔高。

## 点评后的确认动作

每次完成学员日志点评后，默认补一句简短确认：

`如果你要，我可以基于这几条日志再提炼一版圈友共识问题和统一建议。`

不要一次问很多问题，也不要做成多选题。

## 提炼步骤

1. 先看最近几条日志和 `knowledge-base/02-答疑案例/` 里已沉淀的同类案例
2. 只抓重复出现的东西，不抓个别人的偶发问题
3. 按下面四类归纳：
   - 共识问题
   - 常见误区
   - 统一建议
   - 现在最该先做的动作
4. 写成适合群里直接发的短文，不写成报告

## 提炼维度

优先看这些重复信号：

- 大家是不是都卡在效率，而不是卡在完全不会
- 大家是不是都过早放大动作，比如多账号、多风格、多链路
- 大家是不是都没有固定模板，导致每次从零开始
- 大家是不是都在追求精细化，却没先跑通发布测试
- 大家是不是都在文案 AI 味、审核风险、图文匹配、节奏感上反复出问题

## 输出要求

- 不讲空泛方法论
- 直接说“最近大家反复撞到的坑是什么”
- 每条建议都尽量落到动作
- 默认中文
- 默认像群里教练统一提醒，不像课程讲稿

## 推荐结构

```md
这几天看下来，有几个共性问题挺明显，我集中说一下。

{{共识问题}}

{{统一建议}}

{{一句收口：先做什么，不要先做什么}}
```

## 去 AI 味提醒

- 少讲“共识、认知、路径、方法论”这些词
- 多讲“大家最近都在哪一步卡住了”
- 多写动作，少写判断
- 允许带一点教练判断，不要装中立总结机
