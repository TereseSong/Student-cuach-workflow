# 通用教练知识库目录

把后续上传的训练营、航海、课程、答疑、案例资料优先放到这个目录，再让 skill 先检索这里。

## 装好 skill 后先做什么

最简单的用法有两种：

1. 直接贴一条学员日志，让 skill 点评
2. 先把项目资料放进这个 `knowledge-base/`，再让 skill 检索后点评

对用户来说，常见说法可以很简单：

- `用 student-coach-workflow 点评这条日志`
- `先查 knowledge-base，再回答这个问题`
- `帮我把这批资料整理进 knowledge-base`

如果你现在手里资料还很乱，也不用继续拆很多层，就按下面两类放。

建议结构：

- `01-项目知识库/`
  放课程、项目知识手册、收藏的知识、SOP、外部整理资料
- `02-答疑案例/`
  放答疑记录、优秀日志、案例拆解、示范点评、常见问题

新增约定：

- 每次点评或答疑后，最终采用的答复要回写到 `02-答疑案例/`
- 优先追加到 `02-答疑案例/教练点评迭代案例库.md`
- 后续同类任务先查这里，复用已经验证过的话术和纠偏方式

使用约定：

1. 新资料先放这里，不要散落到别的目录。
2. 文件名尽量带主题，例如 `发布节奏-SOP.md`、`低转化-常见原因.md`。
3. 一份资料只讲一个主题，后续检索更稳。
4. 如果是外部内容，建议在文首标注来源链接和整理日期。

## 不同资料怎么放

- 课程、项目知识手册、收藏的知识、SOP：
  放 `01-项目知识库/`
- 外部文章摘录、官方资料整理：
  也放 `01-项目知识库/`
- 群答疑、案例拆解、优秀日志、示范点评：
  放 `02-答疑案例/`
- 暂时分不清：
  优先放 `01-项目知识库/`

检索优先级：

1. 用户点名文件
2. `knowledge-base/`
3. 当前项目其他资料
4. 外部来源补检索
